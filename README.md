# AI業務改善ナビ

**小さな会社・個人事業のための、無料で使える業務改善プラン作成ツール（試作品）**

公開ページ： https://haruto9519-cell.github.io/ai-workflow-navigator/

## できること

- 業種と見直したい業務を選ぶ
- 作業頻度・1回あたりの時間・スタッフ数から、月間作業時間の目安を計算する
- 業務を効率化するための進め方や、実行プランのたたき台を作る
- プランをコピーして、社内で検討する

## 使い方

1. 上の公開ページを開きます。
2. 業種・業務内容・作業頻度などを入力します。
3. 改善プランを作成し、表示された手順を確認します。
4. 必要に応じて実行プランをコピーして、自分の業務に合わせて修正します。
5. ページ下部の「改善のためのフィードバック」から感想をコピーできます。感想は自動送信されません。

## ご利用前に

- このサイトは、業務改善を考えるための**ルールベースの試作品**です。実際に外部のAIサービスへ問い合わせているわけではありません。
- 作業時間や削減見込みは入力値・仮定に基づく目安で、実際の効果や費用削減を保証するものではありません。
- 提案された手順は、実際の業務ルール・契約・セキュリティ要件に合わせて確認してください。
- 氏名、顧客情報、パスワード、その他の機密情報は入力しないでください。
- 本ツールは専門家による業務監査や法務・会計・情報セキュリティ上の助言を代替するものではありません。

## フィードバック

改善したい点や、追加してほしい業務の種類があれば、公開ページ下部のフィードバック欄を利用してください。コピーした内容を共有するかどうかは利用者自身で選べます。個人情報や機密情報は含めないでください。

## 開発状況

本プロジェクトは試作品です。利用者からの反応をもとに、説明の分かりやすさや対応業務の幅を改善していく予定です。
